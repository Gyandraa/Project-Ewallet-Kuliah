✅ 1. Strive for Consistency (Konsistensi)

👉 Tampilan dan interaksi harus seragam di seluruh aplikasi.

Contoh di e-wallet:

Tombol “Kirim” selalu warna sama (misalnya hijau)
Icon saldo, transaksi, top-up tidak berubah-ubah
Format angka selalu sama (Rp 10.000, bukan kadang 10000)

✅ Kenapa penting: user jadi cepat paham tanpa mikir ulang.

✅ 2. Enable Frequent Users to Use Shortcuts (Sediakan Shortcut)

👉 User yang sering pakai aplikasi harus bisa lebih cepat.

Contoh:

Fitur “Transfer Terakhir” atau “Favorit”
Quick button: “Top Up”, “Bayar QR”, “Kirim”
Autofill nomor rekening

✅ Ini bikin user power-user jadi nyaman banget.

✅ 3. Offer Informative Feedback (Berikan Feedback Jelas)

👉 Setiap aksi harus ada respon dari sistem.

Contoh:

Setelah transfer: “Berhasil dikirim”
Loading saat proses transaksi
Notifikasi saldo berkurang

✅ Jangan bikin user bingung: “ini berhasil atau gagal?”

✅ 4. Design Dialog to Yield Closure (Berikan Akhir yang Jelas)

👉 Setiap proses punya awal → proses → selesai.

Contoh:

Step transfer:
Input tujuan
Konfirmasi
Sukses ✅
Halaman “Transaksi Berhasil”

✅ User merasa “selesai”, bukan menggantung.

✅ 5. Offer Simple Error Handling (Penanganan Error Sederhana)

👉 Error harus jelas dan mudah dimengerti.

Contoh:

❌ “Error code 502”
✅ “Saldo tidak cukup”

Lebih baik lagi:

Kasih solusi → “Silakan isi saldo terlebih dahulu”

✅ 6. Permit Easy Reversal of Actions (Bisa Dibatalkan)

👉 User harus bisa undo / batal.

Contoh:

Tombol “Batal” sebelum transfer
Konfirmasi sebelum kirim uang
Undo saat hapus daftar favorit

⚠️ Penting banget di e-wallet karena menyangkut uang.

✅ 7. Support Internal Locus of Control (User Pegang Kendali)

👉 User merasa dia yang mengontrol sistem, bukan sebaliknya.

Contoh:

Tidak auto-transfer tanpa konfirmasi
User bebas pilih metode pembayaran
Tidak ada pop-up yang memaksa

✅ Jangan bikin user “dipaksa sistem”.

✅ 8. Reduce Short-Term Memory Load (Kurangi Beban Ingatan)

👉 Jangan paksa user mengingat terlalu banyak.

Contoh:

Simpan daftar rekening tujuan
Tampilkan riwayat transaksi
Gunakan icon + label (bukan cuma icon)

❌ Buruk: user harus hafal nomor rekening
✅ Baik: tinggal pilih dari list
